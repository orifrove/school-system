# Оплаты в родительском меню

После перезапуска бота: `/children` → ребёнок → **💳 Оплаты**.

Родитель видит начисленные суммы, внесённые платежи и остаток по каждому
периоду обучения. Сводка охватывает все периоды, список показывает по пять.
Кнопка «История платежей» открывает даты и суммы платежей выбранного периода;
«Обновить» перечитывает данные. Время платежей — Ташкент.

## Правила расчёта

- Начисление берётся из сохранённого `BillingPeriod.amount_due`.
  Изменение цены зачисления не меняет ранее выставленное начисление.
- Внесено = сумма связанных `Payment.amount`, с точной Decimal-арифметикой.
- Остаток = max(начислено − внесено, 0); переплата = max(внесено − начислено, 0).
- Общий остаток — сумма остатков отдельных периодов. Переплата по одному
  периоду автоматически не переносится на другой.
- Подпись «Оплачено / Частично оплачено / Не оплачено» вычисляется из сумм.
  Сохранённое поле `BillingPeriod.status` не изменяется при просмотре.
- Нулевое начисление с нулевым остатком показывается как оплаченное.
- Периоды завершённых и индивидуальных зачислений также доступны.

В текущей схеме нет валюты: показываются числовые суммы в единицах учёта
центра, без добавления неподтверждённого обозначения валюты. Это просмотр
зарегистрированных администратором платежей; онлайн-эквайринг не подключён.
Внутренний комментарий платежа и данные сотрудника родителю не выводятся.

## Доступ и проверка

При каждом нажатии проверяются активность пользователя и ребёнка, роль Parent,
актуальная связь ParentStudent и принадлежность периода этому ребёнку.
Чужой ID периода в кнопке не даёт доступа к истории платежей.

```powershell
python manage.py test billing.tests.test_parent_views --noinput
```

14 тестов проверяют частичные платежи, переплаты, точность сумм, общую сводку
на нескольких страницах, историю с одинаковыми датами, зафиксированные цены,
доступ, устаревшие кнопки, экранирование HTML и отсутствие записи при просмотре.
Живую проверку выполняют родительским аккаунтом с существующей связью с учеником.
Если начислений нет, бот покажет пустой список; демо-платежи автоматически не создаются.
